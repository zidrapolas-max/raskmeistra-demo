# Sutvarkystau peržiūra

Ši GitHub Pages nuoroda rodo statinę pagrindinio puslapio peržiūrą iš dabartinės vietinės programėlės. Ji leidžia pamatyti dizainą ir turinį; prisijungimas, paskyros, užklausos bei kitos serverinės funkcijos čia neveikia.

Pilnai veikianti programėlė naudoja Next.js, SQLite ir serverio veiksmus, todėl jai reikia atskiro serverio diegimo. Šiame repozitoriume sąmoningai publikuojama tik statinė peržiūra.
